# Как делать такой гайд — памятка

Готовая страница: `neiro-pack/3d.html`
Живой адрес: https://pro999mega.github.io/playerok-proekty/neiro-pack/3d.html

## 1. Структура папки

```
neiro-pack/
├── 3d.html              ← сама страница
├── index.html           ← старый текстовый гайд
└── img/
    ├── Screenshot_20261031-004721.jpg   ← главный экран, стоит в 3D-телефоне
    ├── Screenshot_20261031-004728.jpg   ← меню режимов, шаг 02
    └── Screenshot_20261031-004735.jpg   ← список моделей, шаг 04
```

Пути к картинкам пишутся **относительно html-файла**: `img/имя.jpg`.
Никаких `/img/` или полных адресов — иначе 404.

## 2. Как залить картинки с телефона

Прямая ссылка на загрузку в нужную папку:

```
https://github.com/pro999mega/playerok-proekty/upload/main/neiro-pack/img
```

→ choose your files → выбрать из галереи → **Commit changes**.

Кнопки `Add file` в мобильной вёрстке GitHub нет. Если ссылка не открылась:
три точки `…` в правом верхнем углу → **Upload files**, либо в Chrome
включить «Версия для ПК».

**Ловушка:** галерея отдаёт файлы с именами вида `Screenshot_20261031-004721.jpg`.
Либо переименовать при загрузке, либо прописать в коде реальные имена.
Проще второе — имена менять уже потом никто не будет.

## 3. Обязательные приёмы (без них ломается)

| Приём | Зачем |
|:---|:---|
| `touch-action: none` на 3D-сцене | иначе браузер забирает жест под прокрутку |
| `backface-visibility: hidden` на гранях куба | иначе видно куб изнутри и зеркальный текст |
| `e.preventDefault()` в pointermove | страница дёргается вместе с кубом |
| `scroll-snap-type: x mandatory` для карусели | карточки не наезжают друг на друга |
| `?v=N` в конце адреса при проверке | GitHub Pages отдаёт старую версию из кэша |
| заглушка вместо отсутствующей картинки | страница не разваливается, видно имя файла |
| `@media (prefers-reduced-motion)` | отключает анимации для тех, кому мешает |

## 4. Что есть на странице

- Прогресс чтения сверху
- 3D-телефон с наклоном за пальцем
- 7 шагов с нумерацией
- Карусель режимов (Battle / Agent / Side by Side / Direct / Max)
- Куб с шестью задачами, крутится пальцем
- Флип-карточки моделей: GPT, Gemini, Grok, Claude, DeepSeek, Qwen
- Кнопка `3D: вкл / выкл` — выключает все эффекты

## 5. Как проверить после правки

1. Открыть адрес с `?v=N` (N на единицу больше прошлого раза).
2. Картинки видны, а не плашки с именами файлов.
3. Куб крутится пальцем в любую сторону.
4. Карусель листается, точки внизу переключаются.
5. При `3D: выкл` ничего не дёргается.
