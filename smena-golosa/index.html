Раздел 1 — Компьютер

1 ПК — простой вариант

Самый быстрый способ: программа-войсченджер создаёт на компьютере виртуальный микрофон, и любое приложение думает, что это обычный мик. Дальше просто выбираешь его в настройках игры или Discord.

Шаг 1. Скачай программу

Только с официального сайта — не из рекламы и не «взломанную»:

ПрограммаОсобенность
VoicemodПроще всего, есть бесплатный набор голосов
ClownfishПолностью бесплатная, интерфейс простой
MorphVOXГибкая настройка тембра

Шаг 2. Установи и запусти

При первом запуске Windows спросит доступ к микрофону — нажми «Разрешить». Если окно не появилось: Параметры → Конфиденциальность → Микрофон → разрешить приложениям доступ.

Шаг 3. Надень наушники

⚠️ Это обязательный шаг. Если играть через колонки, микрофон услышит изменённый голос из динамиков — получится эхо и вой. Только наушники.

Шаг 4. Выбери микрофон

В программе открой список устройств ввода и выбери свой микрофон или гарнитуру. Там же обычно есть ползунок громкости и кнопка проверки.

Шаг 5. Подбери голос

Выбери эффект из списка и нажми кнопку прослушивания — программа даст послушать тебя в наушниках. Крути высоту тона, пока не понравится.

Шаг 6. Включи обработку

Найди главный переключатель программы (в Voicemod он справа вверху) и переведи его в положение «Вкл». Пока он выключен, голос идёт обычный.

Шаг 7. Переключи микрофон в игре или Discord

Открой настройки звука там, где тебя должны слышать, и в списке устройств ввода выбери виртуальный микрофон:

Voicemod Virtual Audio Device (WDM) · или · Clownfish Voice Changer

После этого говори — голос меняется на лету.

💡 Проверка за 10 секунд: зайди в Discord → Настройки → Голос и видео → «Проверить микрофон». Если слышишь изменённый голос — всё работает.

Раздел 2 — Телефон

2.1 Samsung

На Android смена голоса работает внутри самого приложения: ты записываешь голосовые, отправляешь аудио и говоришь в звонках внутри приложения. Подменить микрофон сразу для всех программ Android без root не даёт — это ограничение системы, а не твоего телефона.

Шаг 1. Открой Play Маркет и найди приложение-войсченджер с пометкой «в реальном времени» / «real time».

Шаг 2. Установи и открой его. На запрос доступа к микрофону нажми «Разрешить».

Если случайно отказал: Настройки → Приложения → нужное приложение → Разрешения → Микрофон → «Разрешить».

Шаг 3. Надень наушники — без них будет эхо.

Шаг 4. Выбери голос или эффект из списка.

Шаг 5. Запиши тестовые 5–10 секунд и прослушай. Если нравится — сохрани настройку.

Шаг 6. Чтобы приложение не выгружалось: Настройки → Приложения → это приложение → Батарея → «Без ограничений».

💡 Нужен голос прямо в игре или Telegram-звонке с телефона? Стабильнее и проще это делать через компьютер — раздел 1, там всё работает без ограничений Android.

2.2 iOS (iPhone)

⚠️ Важно: на iPhone настройка строже, чем на Android. Приложения из App Store не подменяют микрофон другим программам — голос меняется внутри самого приложения. Приложения «вне магазина» ставятся через AltStore, для этого нужен компьютер.

Вариант А — App Store (проще)

  1. Открой App Store, найди приложение-войсченджер.
  2. Установи, открой, разреши доступ к микрофону.
  3. Надень наушники.
  4. Выбери эффект и проверь записью.

Вариант Б — AltStore (если нужно приложение вне App Store)

  1. Понадобится компьютер с Windows или Mac и кабель.
  2. Установи на компьютер AltServer с официального сайта altstore.io.
  3. Подключи iPhone кабелем к компьютеру.
  4. В трее AltServer выбери «Install AltStore» и свой iPhone.
  5. Введи свой Apple ID — он нужен только для подписи приложения, пароль никому не передавай.
  6. На iPhone: Настройки → Основные → VPN и управление устройством → доверься своему Apple ID.
  7. Дальше приложения ставятся через AltStore прямо на телефоне.
⚠️ Бесплатная подпись через AltStore живёт 7 дней, потом приложение нужно обновить повторно через AltStore. Это ограничение Apple, обойти его нельзя.

2.3 Redmi (MIUI / HyperOS)

Здесь главное — выдать разрешения, иначе MIUI просто задушит приложение в фоне и оно не будет работать.

Шаг 1. Открой Play Маркет и установи приложение-войсченджер.

Шаг 2. Разреши микрофон: Настройки → Приложения → Все приложения → найди установленное → Разрешения → Микрофон → «Разрешить».

Шаг 3. Отключи экономию заряда (иначе приложение выгрузится):

Настройки → Приложения → Все приложения → [приложение] → Батарея → Без ограничений

Шаг 4. Открой встроенное приложение «Безопасность» (оранжевая иконка на рабочем столе):

  • Разрешения → Микрофон → проверь, что твоё приложение в списке разрешённых
  • Разрешения → Автозапуск → включи для этого приложения
  • Батарея и производительность → Экономия заряда → выбери «Нет ограничений»

Шаг 5. Надень наушники, выбери эффект, проверь записью.

Шаг 6. Закрепи приложение в памяти: открой список недавних задач → свайп по карточке приложения вниз → появится замок.

⚠️ Без шага 3 и 4 смена голоса может не заработать — MIUI выгружает приложение через минуту после сворачивания.
